Family Gmail privacy policy

Last updated: November 2, 2026

Who uses this app

Family Gmail is a private tool for one family's personal use. It is not offered to the public.

What it accesses

With the account holder's permission, the app can read Gmail messages and create drafts in that account. It uses the Gmail read-only and compose permissions. It does not offer a way to send, delete or move email.

How data is used

Email content is retrieved only when the user asks the AI assistant for help with it. The content is passed to that assistant, Anthropic's Claude, to answer the request, and is handled under the user's own agreement with Anthropic.

Storage

The Google sign-in token is stored on the user's own computer. The app's developer runs no server for it and receives no copy of the email or the token.

Sharing

Google user data is not sold, used for advertising, or shared with anyone other than the AI assistant described above.

Removing access

Access can be withdrawn at any time from the Google Account permissions page.

Contact

Questions can be raised through this site's GitHub repository.
